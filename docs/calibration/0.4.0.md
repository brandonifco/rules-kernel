# Calibration for 0.4.0

Runs of `tools/calibration/run.sh` against the consumers pinned in
`tools/calibration/consumers.json` ([decision 0021](../decisions/0021-external-calibration-is-a-release-gate.md)).
If `src/RulesKernel/` or `src/RulesKernel.Analyzers/` changes again before the tag,
`tools/release-checks.py` rejects this record until it is rerun.

**Fidelity.** These runs used SDK 10.0.111 in place of the consumers' pinned 10.0.112, and SDK
8.0.130 in place of SRD_Combat's 8.0.129 (`CALIBRATION_SDKS`), because the pinned patch
releases were not installed on the machine. `publish.yml` reruns the kernel mode at the tag
with the pinned SDK.
